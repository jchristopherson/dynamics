public subroutine solve_flexible_static(mesh, force, conditions, displacement, settings, info, progress, args, multipliers)

Solve static equilibrium on the free equations of a flexible mesh:

Prescribed displacement values are imposed before evaluating the residual. At each iteration the assembled free tangent solves . A residual-norm backtracking search tries the full correction followed by successive halvings. A trial is accepted when it satisfies the convergence tolerance or reduces the residual norm by at least 1.0d-4 * alpha of its previous value.

The free residual norm must be at most absolute_tolerance + relative_tolerance * max(initial_residual_norm, norm2(force_free)). The norm is unscaled across DOFs; force and moment components may need a nondimensionalized model. If all DOFs are prescribed, the solve succeeds without evaluating forces or tangents.

Joints in mesh%joints are enforced with Lagrange multipliers in the augmented Newton system . The tangent omits the multiplier-weighted constraint Hessian, so the iteration is quasi-Newton. Joints require the dense path and at least one free DOF.

Element internal forces must use the positive internal-force convention and their tangents must be consistent derivatives. Evaluations must be safe to repeat at trial displacements; this routine does not commit or roll back history-dependent materials. Force is independent of displacement: follower loads and their tangents are not supported. For prescribed-load increments, call the routine repeatedly with the previous solution as the next guess.

With info, nonlinear or linear-solver failure is reported there and displacement remains unchanged. Without info, such failure causes error stop DYN_CONVERGENCE_ERROR. Invalid inputs and errors raised by the mesh or elements cause an error stop regardless of whether info is supplied.

Arguments

Type IntentOptional Attributes Name
type(finite_element_mesh), intent(inout) :: mesh

Mesh to assemble. Its element workspaces may be modified; do not assemble or solve the same mesh concurrently from callers.
real(kind=real64), intent(in), dimension(:) :: force

Finite, displacement-independent external force in full mesh equation order. Loads on prescribed DOFs are ignored by the equilibrium test but can be used when computing reactions.
type(nodal_condition), intent(in), dimension(:) :: conditions

Prescribed displacements addressed by node-table position and physical DOF label. Values must be finite and DOFs distinct. An empty array imposes no displacement constraints.
real(kind=real64), intent(inout), dimension(:) :: displacement

Finite full displacement vector in mesh equation order. Its free entries are the initial guess; prescribed entries are replaced by condition values on success. On recoverable failure the entire input vector remains unchanged.
type(flexible_static_settings), intent(in), optional :: settings

Optional iteration and linear-solver settings. Omit to use flexible_static_settings defaults.
type(flexible_static_info), intent(out), optional :: info

Optional convergence diagnostics. Supplying this argument makes nonlinear and linear-solver failures recoverable.
procedure(static_solver_callback), optional :: progress

Optional callback invoked after each accepted Newton iterate.
class(*), intent(in), optional :: args

Optional user-supplied data forwarded to the progress callback.
real(kind=real64), intent(out), optional, allocatable, dimension(:) :: multipliers

Optional converged Lagrange multipliers in joint-row order. Allocated only on success; empty when there are no joints.
