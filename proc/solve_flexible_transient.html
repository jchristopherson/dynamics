public subroutine solve_flexible_transient(mesh, times, conditions, initial_displacement, initial_velocity, displacement, velocity, settings, load, args, multipliers)

Integrate a mesh with a dense, constant reference mass. Prescribed displacements are constant and eliminated from the integration equations. The reduced mass must be positive definite. If all DOFs are prescribed and there are no joints, return the prescribed history without assembling mass or evaluating loads.

For meshes without joints the free equations are qdot = v and M*vdot = f_ext - f_int - f_damp. For meshes with joints a private stabilized GGL adapter adds the joint force -transpose(G)*lambda, where G is the constraint Jacobian restricted to free columns. It also adds a kinematic correction to control drift.

With joints, the initial state after imposing supports must satisfy both g(q) = 0 and G(q)*v = 0 within constraint_tolerance. The initial reduced Jacobian must have independent rows. The solver computes consistent multipliers but does not project the input displacement or velocity. Avoid configurations where the joint Jacobian loses rank during the motion.

Invalid inputs and integration failures cause error stop. Moving supports, state-dependent applied loads and inertia, and history-dependent materials are not supported.

Mesh to assemble. Element workspaces may change; do not assemble or solve this mesh concurrently from callers.

Finite initial coordinate rates in full mesh equation order. Prescribed entries are ignored; those rates are set to zero.

Full displacement history, indexed by (mesh DOF, time sample).

Full coordinate-rate history, indexed by (mesh DOF, time sample). Rotational entries are rotation-vector rates, not angular velocity.

Omit to use flexible_transient_settings defaults.
procedure(flexible_load_callback), optional :: load

Smooth applied load. Omit to use zero applied force.

Optional user data forwarded unchanged to load.

Physical joint force multipliers lambda in constraint assembly row order, with one column per time sample. Allocated with zero rows if the mesh has no joints. The kinematic correction multiplier is not returned.
