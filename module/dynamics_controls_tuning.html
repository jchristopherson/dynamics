integral_state_feedback_controller

Derived Types

controller_optimizer integral_state_feedback_controller

Defines an integral state feedback controller along with tools to evaluate its integral squared error (ISE) in closed form and to optimize its gains. Gradients of the ISE with respect to the gains are computed with automatic differentiation.

type, public ::  controller_optimizer

Defines the settings used to optimize the gains of an integral_state_feedback_controller by minimizing the integral squared error of the closed-loop response to a unit step in the reference, plus an optional penalty on the control effort.

Components

real(kind=real64), public :: control_weight = 0.0d0

The non-negative weight applied to the control effort, measured as the integral of the squared rate of change of the control input (the first difference for discrete systems). A value of zero minimizes the integral squared error alone.
