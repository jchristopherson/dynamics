finite_element_mesh mesh_element

Connectivity-based assembly for flexible finite elements.

Elements supply local operators in node-block order. The mesh gathers displacements and sums local contributions using a numbering derived from connectivity, independently of any stored element equation IDs. All outputs are unconstrained: apply boundary conditions separately. With OpenMP enabled, stiffness and internal force may evaluate distinct elements concurrently. Contributions are still accumulated serially in element order. Do not assemble the same mesh concurrently from multiple callers; element evaluations can update their workspaces.

type, public ::  finite_element_mesh

Owns a node table and a heterogeneous collection of elements. Full-layout elements must agree on count and component order at shared nodes. Subset elements attach by matching component labels. Numbering is recomputed on each call.
