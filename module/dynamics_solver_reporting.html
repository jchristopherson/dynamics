static_solver_progress time_history_solver_progress

Provides mechanisms for reporting solver status. Reporting is optional: every progress callback is an optional argument, and solvers do no reporting work when it is omitted. Static solvers report accepted nonlinear iterates, while time-history solvers report completed steps.


Uses

    • iso_fortran_env
