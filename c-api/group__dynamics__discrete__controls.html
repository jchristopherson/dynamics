Detailed Description

Sampled state-space models, transfer functions, and integral feedback.

All routines in this group return 0 on success and -1 for a reported error (see c_get_last_error()). The sample time ts is finite, positive, and in seconds. Models use the existing structs and do not store ts. For state-space models, A, B, C, and D are column-major with shapes N-by-N, N-by-M, P-by-N, and P-by-M, respectively; N may be zero, and M and P must be positive. Empty matrices may have NULL pointers. For discrete transfer functions, coefficients are in ascending powers of z^-1.

Input model storage remains caller-owned. Pass a fresh or freed struct for a model output, distinct from the input. On success, free the result with c_free_state_space_model() or c_free_transfer_function(), as applicable. Arrays passed to the same routine must not overlap.

bool zeros,
int capacity,
double complex * roots,
int * count )

Return poles (zeros=false) or finite zeros (zeros=true) in the z plane.

Zeros require a regular Rosenbrock pencil (including equal input and output counts). Exact zeros at z=0 are retained. Pass capacity=0 and roots=NULL to query count; otherwise pass room for capacity complex values. If capacity is insufficient, returns -1 and sets count to the required size.

◆ c_discrete_integral_feedback_apply()

int c_discrete_integral_feedback_apply ( const c_state_space_model * model,
double ts,
const double * K,
const double * Ki,
c_state_space_model * output )

Allocate the closed-loop model for u=-K*x-Ki*xi and xi_next=xi+ts*(y-r).

Gains are column-major M-by-N and M-by-P; K may be NULL if N is zero. The result has N+P states [x; xi], P reference inputs r, M+P outputs [u; y], and zero feedthrough.
