Detailed Description

Public C interface to the DYNAMICS library.

Matrices use column-major storage to match the Fortran implementation. A matrix with m rows and n columns has leading dimension ld and stores element (i, j) at j * ld + i, using zero-based C indices. Link, joint, and frame indices passed to the mechanism API are one-based. Objects returned by an allocation or creation routine remain owned by the caller and must be released with the corresponding c_free_* routine. Unless documented otherwise, pointer arguments must refer to storage large enough for the dimensions supplied to the routine.
