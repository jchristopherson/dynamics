Controls for solve_flexible_transient. All real-valued settings must be finite.

Positive absolute error tolerance applied to every integrated state component, including algebraic variables when present.
real(kind=real64), public :: constraint_tolerance = 1.0d-8

Nonnegative absolute bound on each initial entry of g and G*v. This is not an integration or drift tolerance.

Upper step-size bound, at least minimum_step_size. It does not set the spacing of the requested output samples.

Positive lower step-size bound in the units of times.

Positive thread count requested for internal-force assembly. Parallel assembly requires thread-safe elements and materials.
