type, public :: flexible_static_settings

Controls the residual test and Newton iteration. Default values are used when solve_flexible_static is called without settings.

Nonnegative absolute free-residual norm tolerance. This and relative_tolerance cannot both be zero.

Maximum halvings of the correction after the full step is tried; zero permits only a full Newton step.

Positive number of threads requested for force and tangent assembly. Parallel evaluation requires thread-safe elements and materials, as documented by finite_element_mesh.
