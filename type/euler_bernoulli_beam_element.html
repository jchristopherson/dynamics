procedure, public :: mass_matrix => eb_mass

  • private subroutine eb_mass(this, m, nodes)

    Compute the constant 12-by-12 consistent reference mass matrix. Four-point Gauss integration combines axial and torsional linear interpolation with Hermite bending interpolation and section rotary inertia. The polar mass moment uses Iy + Iz, not the Saint-Venant torsion constant. The material density must be finite and nonnegative; invalid geometry or matrix shape is an error.

procedure, public :: strain_energy => eb_energy

  • private function eb_energy(this, u, nodes) result(w)

    Integrate the shear-free beam strain energy in the reference configuration. A cubic Hermite centerline is constructed from the chord and rotated end tangents; a projected interpolated director defines the section frame. Axial Green-Lagrange strain is evaluated on the centroidal axis; the material supplies bending and torsion energies from the section rotation rates and properties.

    The axial, bending, and torsional material responses are uncoupled. Zero current chord, singular tangent or section frame, and invalid reference geometry or DOF count terminate with an error.

    Arguments

    Type IntentOptional Attributes Name
    class(euler_bernoulli_beam_element), intent(in) :: this

    Beam with an associated material and valid reference section.
    type(hyperdual), intent(in), dimension(:) :: u

    Twelve seeded global translations and rotation-vector DOFs.
    type(fe_node), intent(in), dimension(:) :: nodes

    Caller-owned reference node table.

    Return Value type(hyperdual)

    Total stored energy and its seeded derivatives.
