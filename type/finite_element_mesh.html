type, public :: finite_element_mesh

Owns a node table and a heterogeneous collection of elements. Full-layout elements must agree on count and component order at shared nodes. Subset elements attach by matching component labels. Numbering is recomputed on each call.

procedure, public :: assemble_internal_force

Assemble element internal forces in global equation order. Optional nthreads enables parallel element evaluation.

  • private subroutine assemble_internal_force(this, q, f, nthreads, velocity)

    Gather local displacements and sum element forces at shared DOFs. This preserves the element force sign conventions and applies no external loads or boundary conditions. If velocities are supplied, also add each element's velocity-dependent damping contribution.

    Arguments

    Type IntentOptional Attributes Name
    class(finite_element_mesh), intent(inout) :: this

    Mesh; element routines may update their workspaces.
    real(kind=real64), intent(in), dimension(:) :: q

    Displacements in global equation order, with one entry per DOF. A length mismatch causes error stop.
    real(kind=real64), intent(out), allocatable, dimension(:) :: f

    Newly allocated internal-force vector with one entry per global DOF in equation order. A mesh with no DOFs returns a size-zero vector.
    integer, intent(in), optional :: nthreads

    Requested upper limit on OpenMP threads for element evaluation. Defaults to 1; without OpenMP, evaluation is always serial. Values less than 1 cause error stop. For values above 1, element routines and any shared data (such as material models) must be safe to access concurrently from distinct elements.
    real(kind=real64), intent(in), optional, dimension(:) :: velocity

    Coordinate rates in global equation order.
